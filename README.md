Semantic Gateway: Enterprise API gateway with semantic LLM routing, rate limiting, and prompt sanitization.

---

## 🌟 Key Features

- 🌐 **Semantic LLM Routing**: Routes prompts to optimal model providers based on intent and cost.
- 🛡️ **Prompt Sanitization**: Filters PII, prompt injections, and jailbreak vectors before model execution.
- ⚡ **Low-Latency Caching**: Semantic vector caching to serve identical LLM queries instantly.
- 📊 **Usage & Cost Tracking**: Token-level rate limiting and cost attribution dashboards.

## 🚀 Quick Start

### Prerequisites
- Python 3.9+ / Node.js (depending on module)
- Git

### Installation
```bash
# Clone repository
git clone https://github.com/sohan-a11y/semantic-gateway.git
cd semantic-gateway

# Install dependencies (if python project)
pip install -r requirements.txt
```
